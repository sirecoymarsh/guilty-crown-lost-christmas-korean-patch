# 편의 기능 선택 — 길티 크라운 로스트 크리스마스

만든 때: 2026-11-23 16:40 · 기준: catalog.json 2026-10-27

추천을 미리 골라 두었습니다. 넣지 않을 것은 `[x]`를 `[ ]`로, 넣을 것은 `[ ]`를 `[x]`로 바꾸면 됩니다.
줄 앞의 `id`는 지우지 마세요(다시 읽을 때 씁니다).

이 게임에 맞는 조건: 선택지로 갈리는 이야기다, 엔진 그리기를 우리가 쥘 수 있다(재컴파일·그리기 DLL·고해상도 합성기), 오프닝·엔딩 같은 영상이 있다, 배경음악이 있다, 원작에 장면 회상·CG 감상 표가 있다, 음성이 있다
원작에 이미 있는 것: backlog-voice, fullscreen-toggle, hold-skip, key-full, menu-auto-skip-rows, mouse-full, prev-choice, skip-protect-unread, voice-mode

## 조작

- [ ] `key-full` **키보드로 다 하기** (A) — 원작에 이미 있음 — 그것을 쓴다
  - 원작 단추마다 닿는 키를 둔다. 화면에 나오는 단추가 모두 키로 닿는지 표로 대 본다. 조합키는 쓰지 않는다.
  - 기본값: Enter·Space 넘기기, Esc 메뉴, Backspace 취소, H 대화창 숨기기, Page Up 대화 기록, X·Y 등 원작 단추
- [ ] `mouse-full` **마우스로 다 하기** (A) — 원작에 이미 있음 — 그것을 쓴다
  - 메뉴·세이브 칸·확인 창·옵션·선택지·대화 기록을 마우스로 바로 누른다.
  - 기본값: 왼쪽 = 정하기, 오른쪽 = 메뉴(이야기 중)·취소, 가운데 = 대화창 숨기기, 휠 위 = 대화 기록, 휠 아래 = 넘기기, 옆 단추 = 취소·메뉴
- [ ] `hold-skip` **누르는 동안 건너뛰기** (A) — 원작에 이미 있음 — 그것을 쓴다
  - Ctrl·Shift를 누르는 동안 건너뛰고 떼면 멈춘다. 0.2초 넘게 그 키만 눌러야 시작해서 다른 단축키와 섞이지 않는다.
  - 기본값: Ctrl·Shift, 0.2초
- [x] `choice-number-keys` **선택지 1~9 키** (A) — 기본
  - 선택지를 숫자 키로 고른다.
  - 기본값: 1~9
- [x] `key-guide` **조작 안내 한 장** (A) — 기본
  - Home으로 모든 키를 한 장에 보여 준다. 바뀐 키를 그대로 보여 준다. 열린 동안 게임 입력을 막는다.
  - 기본값: Home(대화 기록 화면 안에서는 「처음으로」)
- [x] `key-rebind` **키 바꾸기** (A) — 기본
  - PC 환경 설정에서 동작마다 키 두 칸을 바꾼다. 겹침을 막는다.

## 저장

- [x] `quick-save-keys` **저장·불러오기 단축키(S는 다음 빈 칸에 바로 저장)** (A) — 기본
  - S = 칸 고르는 창 없이 다음 빈 칸에 바로 저장하고 잠깐 알린다. L = 불러오기 화면, Q = 빠른 저장(전용 칸).
  - 기본값: S·L·Q
- [x] `save-backup` **세이브 자동 백업·복원** (A) — 기본
  - 저장이 끝까지 성공할 때마다 세대 백업(최근 N)을 남긴다. 고른 백업은 다음 실행 때 복원하고, 복원 직전 지금 세이브도 한 벌 더 떠 둔다.
  - 기본값: 켬, 5세대
- [ ] `save-more-slots` **세이브 칸 늘리기·사진 격자·지우기** (B) — 조건 없음: 원작 세이브 칸이 적다
  - 칸을 늘리고 사진 격자로 보이며, Del로 지우고 메모를 단다.
- [ ] `bookmarks` **책갈피함** (C) — 그 게임 전용 — 원할 때만
  - 세이브 복사본을 장면·요약·음악과 함께 보관한다.
- [ ] `console-save-prompts` **콘솔 저장 안내 줄이기** (B) — 조건 없음: 콘솔판을 PC로 옮긴다(재컴파일·에뮬레이터)
  - 시작 때 저장 장치 안내를 건너뛰고, 시스템 데이터를 확인 창 없이 저장하고, 세이브·설정을 실행 폴더 안에 둔다. 문장 바이트가 같을 때만 자동으로 답한다.
- [ ] `auto-save-before-danger` **전투 직전 자동 저장** (B) — 조건 없음: 전투·게임 부분이 있다
  - 모든 전투가 지나는 대본 맨 앞에 정해 둔 칸으로 자동 저장한다.

## 화면

  - 기본값: Alt+Enter(F11을 엔진이 안 쓰면 F11도)
- [x] `window-memory` **창 크기·위치 기억** (A) — 기본
  - 끌 때 창 자리·크기·최대화·전체 화면을 적었다가 다음에 그대로 연다. 끊긴 모니터 위 자리는 쓰지 않는다. 창 크기를 자유롭게 바꾼다.
- [x] `hd-text` **4K 글자** (B) — 조건 맞음: 엔진 그리기를 우리가 쥘 수 있다(재컴파일·그리기 DLL·고해상도 합성기)
  - 화면을 키워 그리고 한국어 글자는 4K용으로 다시 구운 글꼴로 그린다. 못 만들면 스스로 1배로 돌아간다.
- [x] `hd-art-switch` **그림 4배와 [4K | 원래] 전환** (B) — 조건 맞음: 엔진 그리기를 우리가 쥘 수 있다(재컴파일·그리기 DLL·고해상도 합성기)
  - 그림·글자를 따로 원래/4K로 고르고, 바꾸면 지금 화면을 바로 다시 그린다. 화면 단추와 잠깐 알림을 둔다. 그림 만들기는 vn-art-4k-remaster.
- [ ] `dual-screen-one` **두 화면을 한 화면으로** (B) — 조건 없음: 두 화면 콘솔(3DS·DS)이다
  - 두 화면 콘솔 게임을 PC 한 화면 배치로 보인다. 장면별 배치·위아래 바꾸기.

## 진행

  - 못 건너뛰는 시작 로고를 클릭·키로 건너뛴다.

  - 기본값: 자동 키 A, 끄기 Backspace, 처음 ×1
- [ ] `skip-protect-unread` **읽지 않음 보호** (A) — 원작에 이미 있음 — 그것을 쓴다
  - 누르는 동안 건너뛰기도 「건너뛰기 범위」(읽은 문장만)를 따른다.
  - 기본값: 켬
- [x] `blur-stop-skip` **다른 창으로 옮기면 건너뛰기 멈춤** (A) — 기본
  - 게임 창이 포커스를 잃으면 건너뛰기를 멈춘다. 자동 진행은 그대로 둔다.
  - 기본값: 켬
- [ ] `menu-auto-skip-rows` **메뉴에 「자동 진행」·「건너뛰기」 줄** (A) — 원작에 이미 있음 — 그것을 쓴다

- [x] `auto-continue-after-choice` **선택 뒤에도 자동 진행 계속** (A) — 기본
  - 선택지를 고른 뒤 자동 진행이 꺼지지 않게 한다.
- [ ] `prev-choice` **직전 선택지로 돌아가기** (B) — 원작에 이미 있음 — 그것을 쓴다

## 엑스트라

- [ ] `installer` **설치기·제거** (B) — 조건 없음: 배포할 패치다
  - 게임 꺼짐 확인 → 바뀌는 파일만 백업 → 넣기 → 해시 확인. 해시가 달라도 막지 않고 경고만. 제거는 원본 백업으로 되돌리고, 중단되면 같은 단추로 이어서.
