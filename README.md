# 길티 크라운 로스트 크리스마스 PC판 한국어 패치 작업물

패치 코드·도구·번역 텍스트를 모아 둔 작업 저장소입니다.

원본 게임 파일, 추출한 원문 데이터, 그림·음성·영상, 실행 파일과 빌드 결과는 넣지 않았습니다.
패치를 다시 만들려면 원본 게임이 따로 필요합니다.

## 추가·변경 사항

이 패치가 원작(영문 PC판)에 무엇을 더하고 바꿨는지 정리했습니다. 괄호 안은 근거 파일이고, 「(추정)」은 기록만으로 확정하지 못한 내용입니다.

### 번역 범위

- **본문 대사 전체** — 일본어 원작 대본을 바탕으로 번역했습니다. 기준 번역은 2026-11-17 3차 검수판(2,422 단위 중 705곳 고침)입니다 (`translation-final-20261117/`, `release_1121/진행.md`).
- **영상 자막** — 2장 첫 영상(세피라 게노믹스 설명 영상 `mv_lx0201`), 오프닝·엔딩에 한국어 자막을 넣었습니다 (`release_1121/진행.md`).
- **화면 그림(UI)** — 타이틀·메뉴·설정·아이캐치 같은 그림을 한국어로 다시 그렸습니다. 바뀐 그림 160장과 새 그림 385장을 `cg.kor.npa` 한 묶음에 담았습니다 (`release_1121/진행.md` 「cg.kor.npa」).
- **루비(윗글자)** — 대화 기록 화면까지 루비가 보이게 표를 만들었고, 한국어 강조점 「·」을 일본어처럼 진한 「・」로 바꿨습니다(70곳).
- **노래 가사** — 본편에 나오는 노래 10곡, 366 마디를 원문과 한국어로 함께 보여 줍니다. 본편에서는 화면 위쪽에 상자 없이 노란 한국어 글자로 나옵니다 (`song-timing-20261123/`, `release_1121/진행.md` 「가사 모양」).
- **플레이 중 짚은 번역 고침** — 의성어(「도로롱파」 → 「닌자처럼 펑」, 구토·비명 소리), 번역투 문장(「요염하리만치 새하얀 손이」), 「나한테서 손 치워!」, 「다아트의 사자가 아닌가?」 등을 고쳤습니다. 「카고메 카고메」는 사용자 결정에 따라 그대로 두었습니다 (`release_1121/진행.md` 11-21·11-24).
- **phase 표지** — 「단계」로 번역했던 표지 그림을 원작처럼 영어 「phase」로 되돌렸습니다 (11-24).
- **엔진 문법 대응** — 엔진이 반각 `.` `,`를 멈춤 명령으로 읽어, 대사 안의 것은 `&.` `&,`로 바꿨습니다 (2026-10-25 기록).

### 편의 기능 (원작에 없던 것)

- **설정 셋째 쪽 추가** — 원래 설정 화면 꼴 그대로 셋째 쪽을 더했습니다 (`release_1121/make_cfg_page3.py`, `patch_config.py`).
  - 화질: 4K / 글자만 4K / 원본
  - 초당 프레임: 60 / 120
  - 시작 로고: 보기 / 건너뛰기
  - 이미 읽은 글: 그대로 / 하늘색. 원작에 있던 기능이지만 이 판 설정 화면에는 단추가 없어서 꺼내 놓았습니다.
- **4K 그리기** — 글자와 그림을 4K로 그립니다. 고화질 묶음이 없어도 「4K」는 「글자만 4K」와 같게 동작합니다 (`engine/quality_switch.inc`).
- **창 크기 자유롭게 바꾸기** — 원작 창 모드는 1024x576으로 고정이었습니다. 이제 테두리를 끌어 크기를 바꾸거나 최대화할 수 있고, 마지막 크기·위치를 기억합니다 (`engine/src/window_resize.inc`, 11-23).
- **대화 기록에서 점프** — 대화 기록에서 밑줄 친 줄을 누르면 그 대사로 돌아갑니다. 대화 기록을 여는 속도도 빨라졌습니다 (`engine/backlog_jump*.inc`, `release_1121/backlog_bench.py`).
- **화면 아래 키 목록** — 대사창과 함께 단축키 목록이 나옵니다. 원작 설정 칸과 어울리는 꼴(시안 D)입니다. 회상으로 다시 볼 때는 S·L 칸이 어둡게 나옵니다 (`sound_seek/keybar.py`).
- **본문 언어 바꾸기** — 한국어 / 일본어 / 일한 병기 / 한일 병기 네 가지로 바꿀 수 있습니다. 병기는 한 문장씩 번갈아 보여 주고, 줄 간격은 좁게 했습니다. 대사 도중에 바꾸면 그 대사를 처음부터 다시 보여 줍니다(음성 포함). 일본어 글꼴은 Noto Sans CJK JP(OFL)입니다 (`engine/src/kr_keys.inc`, `jp_twin.py`).
- **바꿀 때 음악 이어 가기** — 언어를 바꾸느라 대사를 다시 불러와도 배경음악이 끊기지 않게 했습니다(bgm_keep v2, 11-25) (`release_1121/진행.md` 「J/K 음악 잇기」).
- **타이틀 「회상」** — 82개 장면을 5x4 격자로 보여 주고 요약을 붙였습니다.
  - 휠로 쪽을 넘깁니다.
  - 장면 상세의 「이 장면의 연출」 단추를 누르면 그 연출 바로 앞부터 장면 끝까지 이어서 재생합니다(28개 장면, 장면당 최대 5개).
  - 재생 전에 이야기 상태를 맞춰, 화면이 검게 나오거나 앞 장면 대사가 빠지는 일을 막습니다 (`movie_room/recall_sp.py`).
- **타이틀 「사운드」** — 원작에는 음악 감상실이 없습니다. 19곡과 엔딩곡 「ISOLATION」·「Where am I ?」를 들을 수 있습니다.
  - 재생 중인 곡 줄이 그대로 진행 막대가 되어, 누르면 그 위치로 옮겨 갑니다.
  - 곡 줄에 커서를 올리면 아래 띠에 제목 풀이가 나옵니다. 스포일러가 되는 풀이는 해당 장면을 읽은 뒤에만 보입니다 (`sound_seek/patch_seek.py`, `title_hints.py`).
- **타이틀 「영상」 방** — 원작 CG 감상 꼴의 썸네일 2x2 칸입니다.
  - 오프닝, 아이캐치, 「2장 · 세피라 게노믹스」, 「5장 · 불길 속 질주」를 볼 수 있습니다.
  - 「연출」 쪽에서는 본편 연출 49곳을 따로 다시 볼 수 있습니다 (`movie_room/`).
- **그 밖** — 타이틀 위아래의 짙은 띠를 없앴고, 첫 장면 크레딧의 작은 글자를 지웠습니다. 문장 끝 아이콘(광물·유전자)은 고해상도로 다시 그렸습니다 (`icons_hd/`, 11-24).

### 화면·그래픽 개선

- 4K 글자 그리기. 작은 루비 글자의 왼쪽 가장자리가 흐려지던 문제도 고쳤습니다.
- 4K 그림을 갈아 끼웁니다. 그림은 따로 내는 고화질 묶음에 담깁니다.
- 초당 120프레임을 고를 수 있습니다.
- 「글자만 4K」로 두면 그림은 원본 그대로 두고 글자만 선명하게 할 수 있습니다.

### 버그 수정

- **2장 첫 영상 멈춤** — MPEG-1 그릇 안에 MPEG-2 영상이 든 파일이라 멈췄습니다. 다시 인코딩해 고쳤습니다 (11-23).
- **창 크기를 바꾼 뒤 클릭이 안 먹던 문제** — 전체 화면으로 갈 때 엔진이 새로 만드는 창 때문에 좌표가 어긋났습니다 (11-23).
- **창을 닫아도 프로세스가 남던 문제** (11-24).
- **회상에 들어가면 꺼지던 문제** — 엔진은 장면 하나에 글 덩어리를 512개까지만 받습니다. 대사마다 실은 언어 판을 6벌에서 4벌로 줄여 고쳤습니다 (11-24, `claude-work/gclx-recall-crash/`).
- **사운드에서 곡이 나오는 동안 다른 곡·멈춤 단추가 안 먹던 문제** (11-24).
- **옛 세이브에서 아래 키 목록이 안 나오던 문제** (11-24).
- **일본어 상태에서 장면 연출 코드가 깨지던 문제** — 241개 덩어리에서 생겼습니다 (11-24).
- **엔진 잠금(lockfix) 고침** (`release_1121/진행.md`).

### 설치·제거 방식

- **본 패치(1.0)** — GitHub 릴리스 `patch-1.0`의 `GuiltyCrownLostXmas_KoreanPatch_1.0_xdelta.zip`(약 336MB)입니다. 원본 게임 파일은 들어 있지 않은 차분판입니다.
  1. 영문 PC판 게임 폴더에 압축을 풉니다.
  2. 「한국어패치_설치.bat」을 실행합니다.
  3. 실행 파일, `nss.npa`, `system.npa`, 영상 3편이 xdelta로 그 자리에서 고쳐지고, 한국어 파일(`cg.kor.npa`·DLL·글꼴)이 들어갑니다.
- **되돌리기** — 「한국어패치_제거.bat」을 실행하면 원본으로 돌아갑니다. 원본 사본에 설치 → 해시 대조 → 제거 → 원본 복원 시험을 통과했고, Defender 검사에서 위협이 나오지 않았습니다 (릴리스 설명).
- **원본 파일은 고치지 않습니다** — 한국어 그림은 원본 `cg.npa`를 고치지 않고 따로 `cg.kor.npa`에 담습니다. 엔진이 이름순으로 먼저 읽은 묶음을 쓰는 점을 이용했습니다.
- **고화질 묶음** — 4K 그림, 4K 오프닝·GC 영상, 2장 영상 4K가 들어가며 약 5.3~5.5GB입니다. 나중에 따로 냅니다. 아직 공개하지 않았습니다.

### 알려진 문제

- **옛 세이브는 옛 대사를 보여 줍니다** — 세이브에 그때 장면 대본이 담기므로, 패치 전이나 이전 판 세이브를 불러오면 그 장면이 끝날 때까지 옛 글이 나옵니다.
- **고배율 화면에서 창이 화면 밖으로 넘칠 수 있습니다** — 창 테두리를 끌어 줄이세요.
- **NTFS가 아닌 드라이브(exFAT 등)에서는 일부 그림이 영어로 보일 수 있습니다** — 그런 드라이브는 묶음을 이름순이 아니라 만든 순서로 읽을 수 있어, 바뀐 그림 160장이 영어로 나올 수 있습니다. 실제로 확인하지는 않았습니다(추정).
- **언어 바꾸기는 회상 재생 중에 다음 대사부터 적용됩니다.**
- **3장 끝(lx0304)에서 드물게 튕깁니다** — 시험 환경에서 튕김이 관찰됐고, 원인은 아직 모릅니다. 음악 이어 가기와는 무관하다고 확인됐습니다.
- **J 키 충돌 여부를 확인해야 합니다** — 원작의 J(직전 선택지)와 언어 바꾸기 J가 겹치는지 기록에 확인이 없습니다(추정).
- **엔딩 롤은 끝까지 다 보며 확인하지 않았습니다.**
- **전투 영상 하나는 영상 방에 없습니다** — 전투 영상 `mvbattle0106`은 장면 안에서만 나옵니다.
